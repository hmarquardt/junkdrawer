About Kraken Market Radar

A single-file browser dashboard for observing Kraken crypto markets. No server. No API keys. No tracking.

Data comes from Kraken's public REST API and WebSocket v2 feeds. All computation happens in your browser.

Keyboard Shortcuts

/ Focus pair search
P Pause / resume live updates
Esc Close panels

Data Sources

  • REST: api.kraken.com/0/public
  • WebSocket: wss://ws.kraken.com/v2
  • Endpoints: SystemStatus, Assets, AssetPairs, Ticker, OHLC, Depth, Trades
