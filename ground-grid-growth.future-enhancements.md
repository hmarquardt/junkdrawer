# Future enhancements

- Add a field-level citation picker for every calculator assumption and proposal
  answer, with archived-file metadata and page/section locators.
- Add a local county profile importer for parcel, soil, zoning, watershed, tax, and
  utility-territory records without introducing a backend.
- Expand saved-scenario comparison beyond fiscal cases to farm, utility,
  environmental, proposal, and term-sheet records.
- Add editable claim subfields and comparison rows through accessible modal forms
  instead of the compact prompt-based Admin controls.
- Add a schema-aware migration preview and conflict resolver for dossier imports.
- Add deterministic calculator unit tests checked into the repository.
- Add optional locally supplied GIS layers and a browser-only parcel/site map.
- Add uncertainty ranges and sensitivity charts for fiscal, farm, power, and water
  scenarios without implying probability where none is known.
- Add a document checklist tied to Indiana zoning, utility, incentive, environmental,
  and public-record stages after legal review.
- Add a citation publication gate that can hide every unverified starter record in
  a “public research” export.
- Add WCAG testing across multiple screen readers and high-contrast modes.
- Add user-selectable print packets combining chosen sections rather than printing
  only the current section or proposal report.
