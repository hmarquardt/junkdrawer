Regex / Ex Cheat Sheet

      

        
:%s/\bcat\b/dog/g
Replace every whole-word cat.

        
:s/foo/bar/
Replace first match on current line.

        
:'<,'>s/foo/bar/g
Replace inside current selection.

        
:g/^ERROR/p
Print matching lines.

        
:g/foo/d
Delete matching lines.

        
:v/foo/d
Delete nonmatching lines.

        
:g/foo/y
Copy matching lines.

        
:42
Jump to line 42.

        
:set ic / :set noic
Toggle case-insensitive regex.

        
:set list / :set nolist
Toggle invisible characters.
