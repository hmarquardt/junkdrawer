Help / About

        
      

      

        
This is a browser-only tool. Closing or reloading the page stops active generation; active requests cannot survive a closed page.

        
API keys in browser applications carry risk. Generated images may consume substantial local storage, and browser download protections may ask for permission when downloading many files.

        
If every request reports “Failed to fetch,” the browser is blocking or failing the direct request before OpenAI returns an API error. Use Test API Key in Admin; if that also fails with a network/CORS message, this copy of the page cannot reach OpenAI directly from the current browser/network.

        
Pricing estimates may be outdated because image pricing can change. Model IDs and API capabilities can also change, so the Admin model field lets you update the model without editing source code.
