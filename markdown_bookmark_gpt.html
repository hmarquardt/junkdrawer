How it works

          

            
1

            
Install
Drag the bookmarklet to your bookmarks bar.

          

          

            
2

            
Clip
Click it on a page. It looks for article, main, or the best available content container.

          

          

            
3

            
Copy
It converts DOM elements into Markdown and copies the result to your clipboard.

          

          

            
4

            
Flourish
A tiny paper-card success animation confirms the clip. If clipboard access fails, it shows a manual copy panel.

          

        


        

          
Diagnostics

          

          
Some pages block bookmarklets or clipboard writes. Browser internal pages, extension pages, strict CSP pages, and some web apps may be cranky.

        


        

          
Privacy & limits

          

            The bookmarklet runs only when you click it. It does not send content anywhere. It copies Markdown locally to your clipboard.
            It does not bypass logins, paywalls, site restrictions, or browser security rules.
          

        

      

    


    
Built as a single local HTML file. No external scripts, no tracking, no remote services. Just a bookmarklet with a clipboard habit.
