📡 Which Big Brother Do We Call?

When Big Brother Mode is on, your prompt is sent to Google Gemini. Local-only mode does not send your prompt to Gemini.

📖 How to get a Gemini API key

  1. Go to Google AI Studio.
  2. Sign in with your Google account.
  3. Create or select a project.
  4. Open the API key section.
  5. Create an API key.
  6. Copy the key.
  7. Paste it into this app’s Admin tab.
  8. Save it locally.
  9. Click Fetch the family tree.
  10. Choose a model that supports generateContent.
  11. Click Test the hotline.
Gemini API docs • API key guide • Models API reference

💳 Billing & Quotas

Some Gemini API usage may require billing depending on model, quota, region, or current Google policy.

  • Go to Google Cloud Console.
  • Select the same project used for the API key.
  • Open Billing and link or create a billing account.
  • Set budgets and alerts.
  • Set API quotas where possible.
  • Avoid using unrestricted high-value keys in browser-only apps.

🛡️ This is not Fort Knox

  • Browser JavaScript cannot hide secrets.
  • localStorage is convenient, not secure.
  • Restrict keys where possible (quota, allowed referrers).
  • Set budgets/alerts.
  • Use a backend proxy or Firebase AI Logic for production.
  • Use this direct-browser mode only for personal tools and prototypes.
