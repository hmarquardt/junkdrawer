What it does

This page generates a bookmarklet. Once saved to your bookmarks bar, you can click it on any webpage to open a right-edge AI palette powered by Chrome’s native built-in AI APIs (Gemini Nano / Prompt API). No cloud calls. No accounts. No tracking.

LOCAL AI TOOLS
To install: Drag the button above to your bookmarks bar. If your browser hides the bar, press Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac) to show it.

Install instructions

  1. Drag the LOCAL AI TOOLS button to your bookmarks bar.
  2. Open any article or webpage you want to analyze.
  3. Click the LOCAL AI TOOLS bookmark.
  4. Use the right-edge AI palette that appears.

The palette can summarize pages, extract key points, translate, answer questions about the page, explain or rewrite your selection, and more.

Help / Troubleshooting

Required browser setup

  • Chrome / Chromium build that exposes built-in AI APIs.
  • Some features may require localhost, an extension context, or an origin trial token.

Useful internal pages

  • chrome://on-device-internals/
  • chrome://components/ — look for Optimization Guide On Device Model
  • chrome://flags/#optimization-guide-on-device-model
  • chrome://flags/#prompt-api-for-gemini-nano-multimodal-input

Common states

  • Unsupported — Not a Chrome/Chromium browser, or APIs are not exposed.
  • API missing — The browser does not expose LanguageModel. Try Chrome Canary/Dev with the right flags.
  • Downloadable — The model can be requested; clicking a task may trigger Chrome to download it.
  • Downloading — Chrome is fetching the model. Keep the page open and retry shortly.
  • Ready — The local model session is active and tasks will run on-device.
  • Unavailable — The model is not available on this device/channel. Check flags and components.

Important limitations

  • Bookmarklets may not run on Chrome internal pages (e.g., chrome://), the Web Store, or sites with strict CSP.
  • Native AI APIs may be unavailable depending on Chrome channel, flags, hardware, origin, and rollout status.
  • A bookmarklet has fewer permissions than a Chrome extension. For production use, consider building an extension.
  • This utility cannot force-install model files; Chrome manages model download, updates, and storage.
