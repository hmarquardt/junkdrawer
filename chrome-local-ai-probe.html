Install / Trigger

    

      Websites cannot force-install the model directly. Calling LanguageModel.create()
      is the normal way to request a session and may trigger Chrome to download the on-device model.
    

    

      This may trigger a large Chrome-managed model download.

Common States

      
    
        
  • API missing — The browser does not expose LanguageModel. Try Chrome Canary/Dev with the right flags enabled.
    • 
        
  • Model unavailable — availability() returned "unavailable". Check internal pages and flags.
    • 
        
  • Download in progress — Chrome is fetching the model. Keep the page open and wait.
    • 
        
  • Session created — The model is ready to use on this page.
    • 
        
  • Hardware/performance requirement failed — Some builds require capable hardware or a performance tier check.
    • 
        
  • Origin trial / flag required — The API may be gated behind an experiment or enterprise policy.
    •
