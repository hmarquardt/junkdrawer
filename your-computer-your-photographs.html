A step-by-step plan

You can do most of this on a computer you already use. Check each step as you complete it. Your checks stay in this browser; this page does not upload your files or contact any AI service.

PATH A · MOST PEOPLEYou can reach the Windows desktop

Great. Do not reinstall Windows. Begin with steps 1–3, then switch your Windows login to a local account in step 4.

PATH B · BRAND-NEW SETUPWindows won't let you finish setup without an account

That is a different issue. Microsoft changes installation requirements frequently. If practical, finish setup and then switch to a local login. Advanced clean-install media tools like Rufus may offer alternatives, but they're not a safe shortcut for an existing photo library.

The one rule that matters mostDo not delete, move, or disconnect any cloud photo folders until you've verified separate, complete local copies and a backup. Changing your Windows sign-in does not automatically stop OneDrive.

A · Protect what's yours
01

Locate the real photo files

Microsoft Photos is a viewer, not necessarily the place your originals live. First find the actual files.

Yellow folder icon (File Explorer) → Pictures
  1. Also check OneDrive → Pictures in File Explorer.
  2. Check external hard drives and other photo folders.
  3. Look for camera originals like .NEF, .CR3, .ARW, .RAF, .DNG as well as JPEGs.
If a folder or file shows a little cloud icon, it may not be fully downloaded. Do not assume that a thumbnail means the original is on your disk.
02

Make complete local copies and a backup

For OneDrive-only photos, right-click the relevant folder and select Always keep on this device. Let all downloads finish. Then copy the originals onto a separate drive or into a folder outside OneDrive. Make another backup if possible.

Original photos→Local photo folder→Separate backup

Open a few RAW and JPEG files while offline. Compare folder counts and sizes. Don't erase memory cards or remove cloud copies yet.

03

Check drive encryption before account changes

Settings → Privacy & security → Device encryption

If Device encryption is not listed, search Start for Manage BitLocker (the option varies by Windows edition). If encryption is on, make sure you possess a recovery key stored safely offline. A key can be associated with your current Microsoft account.

Stop if you cannot find the key. Do not disable encryption or reset Windows merely to bypass a login. Recovery keys can be essential to recovering an encrypted drive.

Microsoft: find your BitLocker recovery key ↗

B · Make Windows your own
04

Switch to a local Windows login

Start → Settings → Accounts → Your info

Look for Sign in with a local account instead. Select it, create a local username and password, then sign out and back in.

Already local? If you instead see Sign in with a Microsoft account instead, you're already using a local Windows account. Skip the conversion. Your Microsoft apps might still ask for separate logins.

A local account signs into this PC without relying on an online Microsoft login. It does not remove Windows updates or prevent you from using ordinary desktop programs.

Microsoft: local account instructions ↗

05

Reduce Windows welcome and suggestion prompts

Settings → System → Notifications → Additional settings

Turn off Windows welcome experiences and tips/suggestions if they appear. The labels can vary by Windows version. This reduces promotional interruptions, though it may not eliminate every Microsoft account prompt.

Tip: press Windows key + I to open Settings, then use its search box if a menu has moved.

C · Separate OneDrive from your photos
06

See whether OneDrive is backing up Pictures

OneDrive cloud icon by clock → Settings → Sync and backup → Manage backup

Check the status of Pictures. If backup is on, verify again that your files are fully downloaded and that you have made independent copies outside OneDrive before changing anything.

Microsoft Photos and OneDrive are separate things. Uninstalling Photos does not stop OneDrive syncing.
07

Create a permanent photo archive

Pick a location not inside a synchronized OneDrive folder. It might be C:\PhotoArchive or a dedicated drive such as D:\Wildlife Photos. Check free space—camera RAW files can be enormous.

D:\Wildlife Photos\ 2026\ 2026-10-25_Goose-Pond\ Originals\ Edited\ Exports\

Copy originals here, then verify. Keep RAW files and any XMP sidecar files together. Avoid using a photo application that hides everything in a proprietary library unless you truly want that arrangement.

08

Stop OneDrive folder backup; unlink if desired

OneDrive → Settings → Sync and backup → Manage backup → Pictures

If you're ready, turn off backup of Pictures. Windows may offer choices such as Keep files only on my PC or Keep files only in OneDrive. Read the effect of each choice carefully. The first may remove synchronized copies from OneDrive and affect other devices.

After verifying your independent archive and backups:

OneDrive → Settings → Account → Unlink this PC
Never use Delete as a test. Deletions inside a syncing folder can be propagated. If you're uncertain, leave OneDrive connected until someone helps verify the copies.

Microsoft: manage folder backup ↗ · Unlink OneDrive ↗

D · Choose your photography tools
09

Install a photo viewer you actually like

Start with FastStone Image Viewer. It's fast and lets you browse your normal folders without importing the entire collection. Compare shots, zoom way in, and examine RAW files. Free for personal and educational use; paid licensing applies to commercial use.

10

Set the new viewer as your default

Settings → Apps → Default apps

Find FastStone (or your chosen viewer). Set its associations for .jpg, .jpeg, .png, .tif, .tiff and supported camera RAW extensions. Then double-click a photograph in File Explorer and confirm it opens in the chosen viewer.

You do not need to uninstall Microsoft Photos. Changing the default is normally enough.

Microsoft: change default apps ↗

11

Make a repeatable camera-to-drive routine

Camera SD card→Dated Originals folder→Verify & back up
  1. Use an SD card reader and open the card with File Explorer.
  2. Copy all RAW/JPEG originals to the dated photo folder.
  3. Confirm they open, then back up to another physical drive.
  4. Only then format or reuse the memory card.

Aim for three copies: working drive, separate backup, and another copy stored elsewhere. This can all be done without cloud storage.

You are in control now.Your computer can keep running Windows, but your photos reside in folders you own and your chosen application opens them. A Microsoft account or subscription is not required for this arrangement.

How can AI be helpful?

Think of AI as a patient helper you can talk to in ordinary English. You describe what you're trying to do. It suggests a next step, explains unfamiliar words, and can revise its explanation until it makes sense.

Not science fiction. Not a computer takeover.

It's like having someone beside you who doesn't mind the fifteenth question.

AI tools such as ChatGPT can answer a question, explain the next Windows setting, help choose photography software, or talk through a problem one screen at a time. You can type naturally—no special commands needed.

You stay in charge. AI can make mistakes. Don't treat it as an authority, and never allow it to delete or reorganize irreplaceable files without understanding the action.
