Welcome to Bashful Stegosaurus

A friendly, local steganography tool for hiding tiny secrets in images and text. Nothing leaves your browser — all processing happens right here on your device.

Image Steganography (LSB)

This tool hides messages inside images using the least significant bits of color values. Think of it like hiding a whisper in a roar — the changes are so tiny that most eyes won't notice.

  • PNG only — JPEG compression will destroy the hidden data. The stegosaurus will forget.
  • Works on RGB channels, leaving alpha untouched
  • Capacity depends on image size: approximately width × height × 3 / 8 bytes
  • Includes a small header so the tool can identify payloads reliably
🦕 PNG only. JPEG makes the dinosaur forget.

Text Steganography (Invisible Unicode)

Hidden messages are encoded using invisible Unicode characters:

  • Zero-width non-joiner (U+200C) represents bit 0
  • Zero-width joiner (U+200D) represents bit 1
  • A magic header identifies genuine payloads
  • Invisible characters are appended to your visible text
🔍 This method can be detected by careful text analysis tools.

Encryption

If you provide a passphrase, your message is encrypted before embedding:

  • PBKDF2 key derivation (100,000 iterations)
  • AES-GCM encryption with random salt and IV
  • The tool will prompt for the passphrase during decode
  • Wrong passphrases produce a clear error — no silent failures

Limits

  • Messages are capped at 127 characters to keep payloads small and discreet
  • Longer messages would be easier to spot and more likely to cause issues

Security Note

This is an educational tool for learning about steganography and hiding private notes. It is not a secure communications system. Sophisticated analysis can often detect hidden data, and determined efforts can extract it.

The Philosophy

The stegosaurus is pretending not to know anything. It just wants to help you hide tiny secrets.
