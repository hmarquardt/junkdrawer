Method, caveats, and future fumes
  • This tracks relative overuse, not objective importance. A large term is louder than its own recent baseline, not necessarily the most common word on Earth.
  • Over-Indexed Score blends log-scaled lift, velocity, source spread, and freshness. Fatigue is computed separately so stale clichés can look smoky instead of triumphant.
  • Demo history is built in so the cloud works from static hosting. Live providers can fail because of CORS, rate limits, unavailable endpoints, or source quirks.
  • GDELT is useful for near-real-time news/media language. Mastodon trends expose internal trending signals. HN Algolia exposes public Hacker News search data. Wikimedia Analytics offers cultural attention context and can lag by 24+ hours.
  • Google Trends, Reddit, TikTok, and YouTube would be useful future sources, but public/API access is more fragile or constrained, so they are not active in this MVP.

    How AI Writing Exhaust works
    • This is not AI detection. It measures relative population-level writing drift from a baseline.
    • The Synthetic Prose Index blends lexical lift, phrase lift, structural density, punctuation shift, cross-domain spread, and a false-positive penalty.
    • Seeded data is used where live historical data is unavailable; scores are normalized and intentionally playful.
    • Some signals have high false-positive risk. AI writing tools amplify existing human writing habits, so individual usage is not evidence.
    • Future providers worth exploring include PubMed, arXiv, OpenAlex, Common Crawl, Reddit, YouTube comments, TikTok, and Google Trends, but they are deferred for API and reliability reasons.

    About Lexical Exhaust Cloud

    Lexical Exhaust Cloud is a playful cultural-language radar for words, phrases, structures, and punctuation habits that feel overrepresented relative to their recent baseline. It is built for noticing discourse exhaust: terms that escaped containment, phrases that got templated, and writing habits that suddenly seem to be everywhere.

    The page has two main instruments. The Culture Cloud tracks broad pop-culture and media language fatigue. AI Writing Exhaust tracks population-level language drift associated with the post-LLM era.

    Both views are intentionally static-host friendly. They run in the browser, use seeded history first, and treat live sources as optional context rather than a dependency.

    What This Is

    • A relative overuse radar, not a raw frequency chart.
    • A toy-but-useful way to spot language that is spiking, spreading, mutating, or getting stale.
    • A transparent scoring demo with seeded historical arcs and clear provenance labels.
    • A browser-only Junk Drawer app with no required backend, build step, or account.

    What This Is Not

    • Not an AI detector.
    • Not evidence that any individual sentence, writer, post, article, or document was AI-written.
    • Not a scientific measurement of cultural importance.
    • Not a moral judgment against normal words, good punctuation, or humans who enjoy tidy headings.

    Sources

    The required source is the built-in seeded dataset, which makes the page immediately useful even offline or when APIs fail. Seeded data is deliberately labeled.

    • Demo seeds: synthetic historical-ish data for cultural terms and AI writing signals.
    • Hacker News Algolia: optional tech-discourse signal for terms and phrases where browser access works.
    • Mastodon trends: optional open-social context using public trend endpoints and internal trend scores, not raw frequency.
    • Wikimedia Analytics: optional cultural-attention context, not direct slang or AI-writing frequency.
    • GDELT: stubbed/TODO for news/media timeline volume because browser use and query shape can be fragile.

    Approach

    The Culture Cloud uses an Over-Indexed Score built from lift above baseline, velocity, source spread, freshness, and separate fatigue/saturation handling. Big words are not necessarily common words; they are louder than their own recent past.

    AI Writing Exhaust uses a Synthetic Prose Index: lexical lift + phrase lift + structural density + punctuation shift + cross-domain spread - false-positive penalty. Signals with high false-positive risk are deliberately framed defensively because AI tools amplify existing human writing habits.

    Google Trends, Reddit, TikTok, YouTube comments, PubMed, arXiv, OpenAlex, and Common Crawl would be useful future sources, but they are deferred because access, CORS, historical querying, or API reliability is more constrained.
