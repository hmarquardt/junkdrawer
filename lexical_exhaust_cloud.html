Method, caveats, and future fumes
  • This tracks relative overuse, not objective importance. A large term is louder than its own recent baseline, not necessarily the most common word on Earth.
  • Over-Indexed Score blends log-scaled lift, velocity, source spread, and freshness. Fatigue is computed separately so stale clichés can look smoky instead of triumphant.
  • Demo history is built in so the cloud works from static hosting. Live providers can fail because of CORS, rate limits, unavailable endpoints, or source quirks.
  • GDELT is useful for near-real-time news/media language. Mastodon trends expose internal trending signals. HN Algolia exposes public Hacker News search data. Wikimedia Analytics offers cultural attention context and can lag by 24+ hours.
  • Google Trends, Reddit, TikTok, and YouTube would be useful future sources, but public/API access is more fragile or constrained, so they are not active in this MVP.

    How AI Writing Exhaust works
    • This is not AI detection. It measures relative population-level writing drift from a baseline.
    • The Synthetic Prose Index blends lexical lift, phrase lift, structural density, punctuation shift, cross-domain spread, and a false-positive penalty.
    • Seeded data is used where live historical data is unavailable; scores are normalized and intentionally playful.
    • Some signals have high false-positive risk. AI writing tools amplify existing human writing habits, so individual usage is not evidence.
    • Future providers worth exploring include PubMed, arXiv, OpenAlex, Common Crawl, Reddit, YouTube comments, TikTok, and Google Trends, but they are deferred for API and reliability reasons.
