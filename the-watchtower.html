What This Page Is

The Watchtower is a local-first monitoring console. It pulls public signals from several APIs, normalizes them into one event stream, scores them for severity, weirdness, urgency, novelty, and recency, then lets you scan, filter, archive, and summarize what it found.

What The Top Buttons Do

Run All Watchers Now calls every enabled data source once. Start Auto-Watch repeats scans on the polling interval. Briefing Desk only opens the Briefing Desk tab. It does not generate text until you click Generate Report inside that tab.

Data Sources

NASA DONKI watches space-weather events such as flares, CMEs, storms, and radiation events. GDELT watches global news metadata for unusual coverage patterns. USGS watches earthquake feeds. CoinGecko watches selected crypto market moves.

Briefs And Local AI

Generate Report creates a deterministic Markdown report from stored events and scores. It does not use AI. Local AI is used only when you create a Chrome built-in AI session and then click an event’s AI action or the detail modal’s Generate AI Brief button.

Tabs

Mission Control shows watcher status. Event Stream lists normalized events. Signal Field plots events visually. Watchers configures sources. Briefing Desk builds Markdown reports. Archive exports/imports data. Log shows scan outcomes. Admin stores keys and scoring settings.

Caveats

This is a triage and exploration tool, not a truth engine. Provider APIs can rate-limit requests, news metadata can be noisy, and scores are heuristics. Treat every item as a lead to verify from primary sources.
