# Dani the Pimple Popper — physical-device testing checklist

For the project owner and Dani. **No physical-device result has been recorded yet**; this document is
the procedure, not evidence. Tick each row and note the device, OS and browser version.

## Devices

- [ ] Android phone (mid-range, e.g. Pixel 6a class), Chrome stable
- [ ] Android phone, Firefox stable
- [ ] iPhone (two sizes if possible), Safari
- [ ] iPad or Android tablet, landscape and portrait

## Installation and upgrade

- [ ] Fresh install from the canonical URL; confirm the installed icon and title.
- [ ] Upgrade a device that already has 1.0.1 / 1.1 / 1.3 / 1.4 / 2.0 installed; confirm campaign
      checkpoints, achievements, records, trophies, dailies, spa cash and staff survive.
- [ ] Open the legacy `danny-the-pimple-popper.html` address; confirm it lands on the game.
- [ ] Toggle airplane mode after one visit; confirm the game and all installed expansions open.

## Touch and extraction

- [ ] Hold-to-pressure works with a thumb and with a fingertip.
- [ ] Releasing in the green zone is achievable without precision frustration.
- [ ] Dragging on the stage never scrolls the page during an extraction.
- [ ] PoreScope scanning tracks the finger; no page scroll; hidden chambers register.
- [ ] Instrument cards are easy to hit; disabled instruments are clearly disabled.
- [ ] Completion and the report dialog are reachable one-handed.

## Modes and navigation

- [ ] Header fits at 320 / 360 / 390 / 430 px without overlap; all six entries are tappable.
- [ ] Each expansion opens and returns without losing an active case or appointment.
- [ ] Case files shows the five-experience overview and can be closed.
- [ ] Rotate during a case and during the spa dashboard; layout recovers.

## Midnight and World Book

- [ ] A phase-locked chamber drains after its condition is met; the PoreScope is visible.
- [ ] A supernatural record appears in the clinic panel and in the World Book.
- [ ] A daily disaster generates offline and replays with the same seed.
- [ ] A legendary run survives backgrounding and resumes.

## Day Spa

- [ ] Schedule and perform an appointment interactively; the receipt appears once.
- [ ] Lock the phone mid-appointment, return, and resume the same appointment.
- [ ] Close the day; rent, wages and restock are deducted once.
- [ ] Reload mid-session; the appointment resumes and no revenue is duplicated.
- [ ] Dashboard reads clearly at 360×640; charts are legible; the accounting line reconciles.
- [ ] Hire a technician and delegate a routine appointment; no extraction record is created.

## Quality observations

- [ ] Haptics fire on meaningful events, not continuously.
- [ ] Audio is synchronised with releases; volume and mute work independently.
- [ ] Frame rate during the largest legendary reservoir and the maximum-tier dashboard.
- [ ] Battery and thermal behaviour over a 20-minute session.
- [ ] Any texture seams, abrupt particle disappearance, or tool-contact misalignment (note scene).
