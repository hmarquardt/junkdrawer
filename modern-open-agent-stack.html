The Modern Open Agent Stack

Agents stopped being chatbots. They are becoming distributed software systems.

A capable autonomous system needs perception, tools, memory, reasoning, execution, model access, isolation, orchestration, deployment, and observability. The repositories are interesting. The architecture they form is the real story.

Memory is broader than a vector database

Embeddings help semantic retrieval, but agent memory may also live in relational databases, knowledge graphs, filesystems, Git history, event logs, checkpoints, caches, or domain systems. Different stores preserve different semantics; “memory” is an architectural responsibility, not a single database product.

06 / SKILLS
Instructions as modules

Skills are becoming software

Matt Pocock’s engineering skills and I Have ADHD show two ends of the same emerging layer: reusable procedures for production work and reusable behavioral policies for how the agent communicates.

Why “software” is more than a metaphor

Skills are versioned, installed, selected, composed, tested, and updated. They can behave like libraries, middleware, runbooks, operating procedures, or policy modules. Model capability still matters, but two agents using the same model can behave very differently because their procedural layer differs.
